
# NextCode x JOVI

Câmera Acadêmica Inteligente.

Projeto acadêmico desenvolvido em parceria
com a FIAP e a JOVI.

## Tecnologias

- React
- JavaScript
- Vite
- HTML5
- CSS3

## Instalação

Clone o repositório:

```bash
git clone https://github.com/NextCode-FIAP/Sprint5-Web_Front.git
```

Entre na pasta:

```bash
cd Sprint5-Web_Front
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

## Build

Para gerar a versão de produção:

```bash
npm run build
```

## Estrutura

- `public/`: imagens públicas.
- `src/components/`: componentes React.
- `src/styles/`: arquivos CSS.
- `src/App.jsx`: composição principal.
- `src/main.jsx`: inicialização React.
